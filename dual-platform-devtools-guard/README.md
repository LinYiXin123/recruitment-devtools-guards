# 招聘平台 DevTools 守卫

这是一个完全独立的 Chrome Manifest V3 扩展，把 BOSS 直聘与猎聘的页面防调试兼容逻辑放进同一个安装包。它不依赖之前的两个扩展，也不会加载任何远程代码。

当前版本：`1.1.0`

### 1.1.0 界面更新

- 弹窗升级为分层毛玻璃视觉，使用半透明外框、平台卡片和状态面板。
- 新增青色与橙色环境光晕、玻璃高光和更清晰的启用状态层次。
- 保留键盘焦点样式，并在系统启用“减少动态效果”时关闭漂移动画。
- 本次仅调整本地 HTML/CSS 和版本号，平台守卫及注册逻辑未改动。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本 `extension` 文件夹，也就是包含 `manifest.json` 的这一层。

## 使用

- 点击浏览器工具栏里的蓝橙盾牌图标。
- BOSS 直聘和猎聘各有一个独立开关。
- 点击卡片里的 `www.zhipin.com` 或 `lpt.liepin.com` 会在新标签页打开对应平台。
- 两个都开：两个平台都启用；只开一个：只注册对应平台的脚本；两个都关：两个脚本都不注册。
- 在对应平台页面切换开关时，当前标签页会自动刷新；其他已打开页面需要手动刷新一次。

初次安装时两个开关默认开启。若之前的单平台扩展还在运行，建议先停用它们，避免同一页面重复注入；本扩展本身不依赖它们。

## 作用范围与隐私

- BOSS 直聘：`https://www.zhipin.com/*`
- 猎聘：`https://lpt.liepin.com/*`
- 不申请全站访问权限，不修改登录或业务请求，不采集或上传数据。
- 平台开关只保存在 Chrome 本地存储中。
